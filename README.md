Стартовый G-code

- Отключена повторная проверка вибраций M970.3 / M974, но сама компенсация оставлена (M975 S1)
- Включён параллельный прогрев стола во время остальных стартовых операций, ожидание температуры перенесено ближе к Z-homing
- Отключена проверка check scanner clarity (наличие печатной пластины и чистота лидара)
- Сокращён стартовый purge примерно со 105 мм до 49 мм и увеличена его скорость

Конечный G-code

- Отключена автоматическая выгрузка филамента обратно в AMS после каждой печати - филамент перезагрузится только при смене цвета при следующей печати

Изменения относительно исходного варианта видно в коммитах.
